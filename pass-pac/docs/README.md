# PASS-PAC Docs

Project notes and architecture documents will live here as the application grows.

Current scope:
- Local-first professional dashboard with database-backed sessions
- Dataset-driven simulator and rule-based risk findings

- Controlled experiment batches, trial records, evidence hashes, and statistical summaries
- Anonymized CSV/PDF research reports and baseline-versus-remediation comparison
- Reports folder used for local anonymized research output
- Read-only Proxmark3 bridge on Windows using the matching ProxSpace client
- Authentication and write/clone operations remain out of scope
